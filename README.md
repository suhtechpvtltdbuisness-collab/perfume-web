# Maison Aurélia

A cinematic luxury perfume ecommerce experience built with Next.js, React, TypeScript, Tailwind CSS, Three.js, React Three Fiber, GSAP and Lenis.

## Features

- Scroll-driven 3D perfume bottle and spray animation
- Responsive luxury storefront and product catalogue
- Product galleries with multiple image/video uploads
- Persistent cart, checkout and customer authentication interfaces
- Admin dashboard for landing-page content and product management

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The demo admin dashboard is available at `/admin`.

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```
